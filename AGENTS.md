# Orientações para agentes - AulaHub (SPECTION)

Este repositório utiliza o SPECTION como disciplina de especificação e entrega.

## Fluxo obrigatório
Discover -> Specify -> Architect -> Plan -> Build -> Verify -> Release.

1. Ler `docs/product-brief.md`, `docs/prd.md` e `docs/architecture.md` antes de mudanças.
2. Relacionar cada alteração funcional com pelo menos um requisito (RF/RNF).
3. Não inventar dados acadêmicos, links, datas nem ementas. Marcar informações pendentes como 'A confirmar'.
4. Manter materiais autorais restritos fora do GitHub público e do GitHub Pages.
5. Não implementar falsas proteções de conteúdo por JavaScript ou CSS.
6. Nunca inserir credenciais, tokens, informações pessoais de estudantes ou links de edição.
7. Testar navegação, responsividade, teclado e links antes de publicar.
8. Atualizar documentação e registrar evidências da validação antes da release.
9. Preservar a clareza da interface para estudantes.
10. Usar hífen simples (-) em arquivos Markdown quando for apropriado.
